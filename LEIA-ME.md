# Site da Fachada Tech

## Onde editar cada coisa

- `fonte/conteudo/configuracaoDoSite.js`: textos, telefone, Instagram, links e serviços.
- `fonte/componentes/Cabecalho`: cabeçalho e menu.
- `fonte/componentes/Abertura`: primeira área do site.
- `fonte/componentes/Introducao`: seção que apresenta o problema e o valor do cuidado.
- `fonte/componentes/Servicos`: cartões dos serviços.
- `fonte/componentes/Processo`: etapas de atendimento.
- `fonte/componentes/Contato`: chamada final e redes sociais.
- `fonte/componentes/AvisoCookies`: aviso de cookies.
- `fonte/estilos`: cores, espaçamentos e animações gerais.
- `publico/imagens`: imagens e ícones usados no site.

## Comandos

```bash
npm install
npm run dev
npm run build
```

O endereço local padrão é `http://127.0.0.1:5173/`.

## Observação importante

Os arquivos `package.json`, `index.html`, `vite.config.js`, `.gitignore` e a pasta `.openai` têm nomes técnicos exigidos pelas ferramentas. A pasta `dist` é gerada automaticamente e não precisa ser editada.
